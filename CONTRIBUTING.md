# Contribution Guidelines

## 1. Create a Branch

Create a separate branch for every task.

Example: `feature/student-dashboard`

## 2. Write Clear Commit Messages

Use meaningful messages that explain your changes.

Example: `docs: add contribution guidelines`

## 3. Open a Pull Request

Push your branch and create a Pull Request targeting `main`.

## 4. Review Code

Check the changes, respond to review comments, and ensure required tests pass before merging.
